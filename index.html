📇 个人制卡助手 Markji
通过墨墨开放平台授权，自动生成墨墨记忆卡内容

1 配置 Client ID

✅ 已保存

2 授权登录

点击下方按钮，跳转到墨墨账号授权。授权范围包含 open.markji.content（墨墨记忆卡内容读写）。

尚未获取 Client ID 时无法授权。请先完成第 1 步。

3 使用方法

  1. 在 墨墨开放平台 创建应用，勾选「墨墨记忆卡内容读写 (open.markji.content)」并提交审核；
  2. 审核通过后复制 OIDC Client ID，粘贴到上方第 1 步并保存；
  3. 点击「授权墨墨账号」完成登录授权；
  4. 授权完成后回调页会显示 access_token，将其复制给 AI 助手即可开始制卡。
